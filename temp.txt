When writing and searching for properties, the case of the written characters is not taken into account, there is no difference between the syntax <span class=\"variable-text-block-span-1\">Lmn(MASK 1)</span> and <span class=\"variable-text-block-span-1\">Lmn(mask 1)</span>.<br><br>This variable has its own auxiliary variables <span class=\"variable-text-block-span-1\">mNumber</span>, which can be used instead of the mask name, for example: <span class=\"variable-text-block-span-1\">Lmn(m1, m2, m3, [ / ])</span>, this syntax will return the first, second, and third mask names. If the third mask, for example, is not present on the layer, an empty value will be returned instead.<br><br>This variable supports a special variable <span class=\"variable-text-block-span-1\">prop</span>, instead of specifying property names, you can simply select them on the required layer. Example syntax: <span class=\"variable-text-block-span-1\">Lmn(prop, mask2, m3)</span>. For example, if you selected three properties on the layer: <span class=\"variable-text-block-span-1\">mask 1</span>, <span class=\"variable-text-block-span-1\">mask 2</span>, <span class=\"variable-text-block-span-1\">mask 3</span>, these properties will be substituted instead of the variable <span class=\"variable-text-block-span-1\">Lmn</span>.<br><br>
