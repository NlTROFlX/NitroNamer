The variable <span class=\"variable-text-block-span-1\">T</span> returns the layer type. You can set a filtering mode, in which case names are returned only for layers whose type matches the specified one. Values that can be used for filtering: <span class=\"variable-text-block-span-1\">shape</span>, <span class=\"variable-text-block-span-1\">text</span>, <span class=\"variable-text-block-span-1\">pre-comp</span>, <span class=\"variable-text-block-span-1\">null</span>, <span class=\"variable-text-block-span-1\">adjustment</span>, <span class=\"variable-text-block-span-1\">footage</span>, <span class=\"variable-text-block-span-1\">solid</span>, <span class=\"variable-text-block-span-1\">light</span>, <span class=\"variable-text-block-span-1\">camera</span>, <span class=\"variable-text-block-span-1\">audio</span>. You can use an enumeration in filtering mode, for example: <span class=\"variable-text-block-span-1\">T(solid, shape)</span>. In this case, names will be returned/changed only for layers that match the filtering values, while others will remain unchanged.
