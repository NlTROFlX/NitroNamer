The variable <span class=\"variable-text-block-span-1\">Lsc</span> returns the current scale value of the layer. If the layer is not a 3D object, it will return a value in the <span class=\"variable-text-block-span-1\">x, y</span> format, otherwise — in the <span class=\"variable-text-block-span-1\">x, y, z</span> format.
