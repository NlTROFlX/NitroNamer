Переменная <span class=\"variable-text-block-span-1\">Lexp</span> возвращает имена свойств слоя, у которых активирован <span class=\"variable-text-block-span-1\">Expresion</span>. Можно задать режим фильтрации <span class=\"variable-text-block-span-1\">Lexp(property1, property2)</span>. В этом режиме переменная возвращает только указанные свойства, у которых активирован <span class=\"variable-text-block-span-1\">Expression</span>. Количество перечисляемых свойств не ограничено. Замена разделяющего символа осуществляется с помощью синтаксиса <span class=\"variable-text-block-span-1\">Lexp([#])</span>. Виды синтаксиса для использования: <span class=\"variable-text-block-span-1\">Lexp</span>, <span class=\"variable-text-block-span-1\">Lexp([#])</span>, <span class=\"variable-text-block-span-1\">Lexp(property1, property2)</span>, <span class=\"variable-text-block-span-1\">Lexp(property1 [#])</span>.
