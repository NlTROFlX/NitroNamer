The <span class=\"variable-text-block-span-1\">Tm</span> variable returns the <span class=\"variable-text-block-span-1\">Track Mate</span> type for the layer(s), both for the source layer and the conditionally child layer. It returns a value in the <span class=\"variable-text-block-span-1\">TM:value</span> format. The values that can be returned by this variable are: <span class=\"variable-text-block-span-1\">alpha</span>, <span class=\"variable-text-block-span-1\">luma</span>, <span class=\"variable-text-block-span-1\">alpha inverted</span>, <span class=\"variable-text-block-span-1\">luma inverted</span>.
