The variable <span class=\"variable-text-block-span-1\">Fext</span> returns the extension name for materials of various types: video, images, audio, <span class=\"variable-text-block-span-1\">Photoshop file</span>, <span class=\"variable-text-block-span-1\">AI file</span>, and similar ones—in general, everything that is not created directly in Adobe After Effects. There is a filtering mode <span class=\"variable-text-block-span-1\">Fext(extensionName)</span>, where <span class=\"variable-text-block-span-1\">extensionName</span> can be any file extension. Enumeration can be used, for example: <span class=\"variable-text-block-span-1\">Fext(ai, psd, png)</span>. If a layer has no extension, the value from the settings is returned for it.
