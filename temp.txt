The variable <span class=\"variable-text-block-span-1\">R</span> returns the width and height of the layer source in pixels in the format <span class=\"variable-text-block-span-1\">x*y</span>. There is a rounding mode after the decimal point — <span class=\"variable-text-block-span-1\">R(N)</span>, where <span class=\"variable-text-block-span-1\">N</span> is the number of decimal places returned. It takes values from 1 to 9.
