The variable <span class=\"variable-text-block-span-1\">Lpos</span> returns the current position value of the <span class=\"variable-text-block-span-1\">Anchor point</span> of the layer. If the layer is not a 3D object, it will return the value in the <span class=\"variable-text-block-span-1\">x, y</span> format, otherwise — <span class=\"variable-text-block-span-1\">x, y, z</span>.
