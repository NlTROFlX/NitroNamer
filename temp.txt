Переменная <span class=\"variable-text-block-span-1\">Lmn</span> возвращает имена всех масок, которые есть на слое. Можно задать режим фильтрации <span class=\"variable-text-block-span-1\">Lmn(nameMask1, nameMask2)</span>; в этом режиме переменная возвращает только указанные имена масок, если они есть у слоя. Количество перечисляемых имен масок не ограничено. Замена разделяющего символа осуществляется с помощью синтаксиса <span class=\"variable-text-block-span-1\">Lmn([#])</span>. Некоторые виды синтаксиса для использования: <span class=\"variable-text-block-span-1\">Lmn</span>, <span class=\"variable-text-block-span-1\">Lmn([#])</span>, <span class=\"variable-text-block-span-1\">Lmn(nameMask1, nameMask2)</span>, <span class=\"variable-text-block-span-1\">Lmn(nameMask1 [#])</span>.
