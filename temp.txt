When writing and searching for properties, the case of the entered characters is not considered. There is no difference between the syntax <span class=\"variable-text-block-span-1\">Lmc(MASK 1)</span> and <span class=\"variable-text-block-span-1\">Lmc(mask 1)</span>.<br><br>This variable has its own auxiliary variables <span class=\"variable-text-block-span-1\">mNumber</span>. These variables can be used instead of the mask name, for example: <span class=\"variable-text-block-span-1\">Lmn(m1, m2, m3)</span>. This syntax will return the first, second, and third mask names. If the third mask, for example, is not present on the layer, then an empty value will be returned instead of its name.<br><br>
