The variable <span class=\"variable-text-block-span-1\">prop</span> returns the names of any selected property groups of a layer that were highlighted on the selected layer in the timeline panel or the effects control panel. For all other layers, the existence of a similar group or groups is checked along the same path as in the layer where they are selected. If such groups exist, they will be returned as the name for the layer; otherwise, a value indicating that such groups do not exist for the layer will be returned. Multiple selection of groups on other layers will not return all selected groups on all selected layers, but only for the last selected layer.
