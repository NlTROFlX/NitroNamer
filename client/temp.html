INTRODUCTION

Panel:

Possibilities

- Offline documentation with technical specifications and usage examples for each variable.

- Importing saved templates

- Export saved templates

- Review of the Change Log of the current version of NitroNamer

- License Overview

Navigation:

Left side

- On the left side of the panel there is a list in the form of spoilers, each spoiler is a separate category of variables. By clicking on the spoiler, you will open a list of all available variables of this category. Each sub-item is a separate variable.

- By clicking on any sub-item, you will see a detailed description of the variable you have opened.

- The circular blue indicator next to the spoiler displays the total number of available variables from the category you selected.

Description of variables:

Right side

- Each variable has 4 sections: technical specifications, description, features, examples.

- In the "Technical characteristics" section there are 4 items, each variable has these 4 items. Item 1 - the number of available operating modes, item 2 - setting the return value (yes/no), item 3 - setting the custom separator, item 4 - the source of the value.

- The Description section describes what this particular variable does and returns.

- The "Features" section describes any unusual or non-obvious properties or actions of the variable.

- The Examples section shows some uses of the variable.

CHANGE LOG 2024.4

Features:

UI

- Tooltips for UI elements.

- System for searching and sorting saved presets (search by entered value, by date added, by usage statistics, by favorites, by template length).

- Completely new library of variables.

Variables:

- Improved syntax logic for variables E, An, Lexp, Lmn, Lmc, Ec

Bug fixes

- When using the F variable, the preview field displays the value "NaN" with any Briefly mode active, but the result itself is applied correctly to the layers.

- When using any "Briefly" mode, the preview field displays the result not after applying "Briefly" but before it, i.e. not formatted. But the final result of renaming layers is correct, i.e. taking into account the selected "Briefly" mode.

- Variables E, An, Lexp with the filtering mode for a given effect/property now correctly handle situations when the composition contains layers with this effect/property or their absence (see the changes section, first point).

- Now the variables `Lmn`, `Lmc` correctly recognize the names of masks and their operating modes.
